## 评分算法

8 大类信号，满分 100，base=50：

| # | 信号类别 | 最大加分 | 检测项 |
|---|---------|---------|--------|
| 1 | 均线系统 | +14 | 多均线跌破、死叉、均线斜率 |
| 2 | RSI | +27 | 超买/超卖、RSI回落、RSI顶背离 |
| 3 | MACD | +35 | 零轴位置、柱体方向、动能衰减、顶背离 |
| 4 | 布林带 | +8 | 触及上轨/下轨 |
| 5 | 成交量+OBV | +28 | 放量下跌、量能趋势、OBV出货背离 |
| 6 | 趋势斜率 | +16 | 短线急跌/急涨、短中期齐下 |
| 7 | K线形态 | +16 | 连续阴线、长上影线抛压 |
| 8 | 波动率 | +6 | ATR扩张 |

### 多周期交叉验证

同时分析日线、4 小时、小时线三个周期，方向一致时加分，矛盾时降权过滤假信号。

## 授权机制

程序启动时读取同目录下的 `TIMELOCKED` 文件（AES 加密的时间锁），与当前时间对比：
- 未过期 → 正常运行
- 已过期 → 提示联系作者续费
